# xxx大学教师公寓管理系统 - 项目介绍

## 一、项目架构

```
┌─────────────────────────────────────────────────────────────────┐
│                    xxx大学信息化平台                          │
│  ┌─────────────────┐    HTTP回调     ┌────────────────────────┐ │
│  │   InfoPlus      │ ──────────────▶ │    sjtu-workflow       │ │
│  │   表单平台/工作流 │ ◀────────────── │    （工作流中间层）      │ │
│  │  form.sjtu.edu  │   RestTemplate  │   接收事件→路由处理      │ │
│  └─────────────────┘                  └──────────┬─────────────┘ │
│                                                  │ HTTP调用       │
│                                                  ▼                │
│                              ┌────────────────────────────────────┐│
│                              │         shjd-sys                   ││
│                              │      （业务后端/数据持久化）        ││
│                              │                                    ││
│                              │  ┌──────────────────────────────┐ ││
│                              │  │ teacher_apartment 模块        │ ││
│                              │  │  租金/财务/协议/报修/物业      │ ││
│                              │  └──────────────────────────────┘ ││
│                              └────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────────┘
```

**架构说明：**
- **sjtu-workflow**：工作流中间层，负责与交大InfoPlus工作流平台交互，接收流程事件回调（Messenger机制）
- **shjd-sys**：业务后端，负责数据持久化和核心业务逻辑
- 两系统通过HTTP/REST解耦，流程引擎与业务逻辑分离，支撑高并发分布式部署

## 四、STAR法则项目介绍

### 【Situation - 背景】

xxx大学教师公寓管理系统面向全校40000+教职工，涵盖房源分配、申请审批、协议签订、租金收缴、退房结算全流程，年均处理公寓申请2000+单、租金收缴金额超5000万元。系统由业务后端（shjd-sys）和工作流平台（sjtu-workflow）两大部分组成，通过HTTP接口与服务端工作流引擎交互，实现业务流程自动化。

### 【Task - 任务】

作为核心开发成员，负责**业务后端（shjd-sys）与工作流平台（sjtu-workflow）的集成开发**，重点深耕**租金管理、财务审核、协议生成、报修管理、物业管理**五大业务模块，对接学校计财处、银行、微信/支付宝等第三方系统，实现"表单流程+业务数据"双通道联动。

### 【Action - 行动】

**架构设计：**
- 设计并实现"工作流中间层（sjtu-workflow）+ 业务后端（shjd-sys）"双层架构
- 通过HTTP/REST解耦流程引擎与业务逻辑，流程事件由Messenger统一路由
- 敏感业务操作经工作流回调触发，支撑高并发场景下的分布式部署

**工作流集成：**
- 基于交大InfoPlus工作流平台SDK，封装Messenger回调机制
- 每个业务流对应独立Messenger类（继承AbstractMessenger）
- 实现流程节点渲染、数据校验、动作触发全生命周期管理
- 支持流程推进、自动审批、事件订阅等复杂场景

**租金管理：**
- 设计并实现租金自动计算引擎，支持基础租金+水电费+物业费+违约金等多种费用项的灵活配置
- 封装租金规则算法，支持特殊减免、优惠政策自动适配，规则变更零代码改造
- 引入Redis缓存租户租金方案，租金查询接口响应时间降低75%

**财务审核：**
- 对接学校计财处WebService接口，实现租金收缴数据自动推送与到账确认
- 设计租金支付多级审核流程（TeacherApartmentRentReview），支持会签/或签等复杂审批场景
- 实现微信/支付宝/银行代扣多渠道支付接入，支付成功率达99.9%
- 封装财务对账模块，自动生成月度/年度租金报表，财务核对效率提升90%

**协议生成：**
- 基于FreeMarker+POI封装协议模板引擎（支持ApartmentSelectionAndSignAgreement、FundsApply等15+种协议类型）
- 一键生成标准Word/PDF协议文档
- 对接学校电子签章API，实现在线签约存档
- 协议生成效率提升80%

**报修管理：**
- 实现公寓报修全流程（ApartmentRepairApply）：提交→派单→接单→完工→评价闭环
- 对接物业维修材料库，自动统计材料消耗
- 支持"交我办"APP消息推送，维修进度实时可见

**物业管理：**
- 设计物业公司信息管理模块（PropertyContractSign）
- 支持物业合同电子化管理
- 对接保洁、安保等第三方服务评价体系

### 【Result - 结果】

- 系统平稳运行3年+
- 日均活跃用户3000+
- 年租金收缴金额超5000万、零漏账
- 审批周期从线下15天缩短至线上3天
- 协议生成效率提升80%
- 用户满意度达95%+

## 七、项目亮点总结

1. **双层架构解耦**：工作流与业务分离，分布式部署支撑高并发
2. **深度工作流集成**：15+业务流程通过Messenger统一管理
3. **多系统互联互通**：对接学校7个部门系统（人事处、计财处等）
4. **高性能缓存**：Redis优化，接口响应时间降低75%
5. **自动化文档生成**：FreeMarker模板引擎，效率提升80%
6. **多渠道支付**：支付成功率99.9%，零漏账
